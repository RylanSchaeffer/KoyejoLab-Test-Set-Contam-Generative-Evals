# ICML 2026 → NeurIPS 2026 — Format Conversion Changelog

Generated by Claude Code while converting the paper *"Quantifying the Effect of Test Set Contamination on Generative Evaluations"* from its ICML 2026 Overleaf project to the NeurIPS 2026 template.

This file records the format conversion and subsequent submission-cleanup edits. The initial conversion preserved paper content; later audit cleanup made limited source-hygiene, checklist, license-disclosure, and typo fixes documented below.

## Source selected

ICML Overleaf project `696e717937bf7dfa6931ddca` contained two manuscript directories:

| Directory | Variant | Decision |
|---|---|---|
| `manuscript/` | Main ICML 2026 conference submission (uses `\usepackage[accepted]{icml2026}`, inputs `07_acknowledgements.tex`, and contains `07_impact_statement.tex` as a source file even though `00_main.tex` does not input it) | **Selected as the source.** Full paper-length version. |
| `manuscript_fdgm_icml_2026/` | FoGen workshop variant for ICML 2026 (uses `icml2026_fogen` style, length-compressed, contributions list and several paragraphs commented-out with `%`) | **Not used.** Workshop-derivative; less complete. |

`git log` history in the ICML project is squashed into a single "Update on Overleaf." commit, so commit timestamps were not informative for picking "freshest." File mtimes were identical (clone artifact). Decision was made by content inspection: `manuscript/` is the source-of-truth full-length paper; the FoGen variant is a derived shortened version. If the user disagrees, they can re-run the conversion against the workshop variant — section text differs in minor wording (e.g., main: "highly likely" vs. fdgm: "likely"; main: "$C \approx 6 N D$" vs. fdgm: "$C = 6 N D$"). See diffs in the upstream Overleaf project history.

## Preamble: ICML packages → NeurIPS preamble

Removed (ICML-only / replaced):

| Removed | Reason |
|---|---|
| `\usepackage[accepted]{icml2026}` | Replaced by `\usepackage{neurips_2026}` (anonymized submission). |
| `\icmltitlerunning{…}` | ICML running-title macro; NeurIPS template has no equivalent. |
| `\bibliographystyle{icml2026}` | ICML bib style; replaced with `plainnat` (common NeurIPS choice) — flagged as a guess. |

Kept verbatim from ICML preamble (NeurIPS template doesn't load these):

- `\usepackage{graphicx}`, `\usepackage{subcaption}`, `\usepackage{multirow}`
- `\usepackage{amsmath}`, `\usepackage{amssymb}`, `\usepackage{mathtools}`, `\usepackage{amsthm}`
- `\usepackage[capitalize,noabbrev]{cleveref}`

Adapted from the ICML preamble:

- `todonotes` is still loaded but disabled via `\usepackage[disable,textsize=tiny]{todonotes}` for submission source hygiene.

De-duplicated (ICML preamble loaded `booktabs` and `cleveref` twice each — single load each in the NeurIPS preamble).

Loaded explicitly in the new preamble (the official NeurIPS template loads these in its own main `.tex` — `neurips_2026.sty` does NOT auto-load them, so they must be `\usepackage`'d):

- `inputenc[utf8]`, `fontenc[T1]`
- `hyperref`, `url`, `booktabs`, `amsfonts`, `nicefrac`, `microtype`, `xcolor`

Auto-loaded by `neurips_2026.sty` and therefore NOT re-added:

- `natbib`
- `geometry`, `lineno`, `environ`, `trimspaces`

Custom commands retained or cleaned:

- `\newcommand{\theHalgorithm}{\arabic{algorithm}}`
- Reviewer-comment macros were removed because no live invocations remained.
- Theorem environments (`theorem`, `proposition`, `lemma`, `corollary`, `definition`, `assumption`, `remark`)
- `\definecolor{legendblue}{…}`, `\definecolor{legendgreen}{…}`
- `\input{math_commands}`

## Figure-path normalization

The ICML source mixed two figure-path conventions. Some files referenced `figures/...` (relative to `manuscript/`), others `manuscript/figures/...` (relative to project root). Building from `manuscript/` per the ICML README, the latter would resolve to a non-existent `manuscript/manuscript/figures/...` — likely a broken build for those figures.

Since the NeurIPS clone is flat (no `manuscript/` subdirectory), all paths are normalized to `figures/...`:

- `05_generation.tex`: `manuscript/figures/14_…` → `figures/14_…`
- `06_discussion.tex`: `manuscript/figures/50/…` → `figures/50/…`
- `99_appendix.tex`: two `manuscript/figures/14_…` → `figures/14_…`

This is a path edit only — figure content is unchanged.
